# نزيه — المساعد الافتراضي لليوم العالمي لمكافحة الفساد (9 ديسمبر)
### جامعة حائل × هيئة الرقابة ومكافحة الفساد (نزاهة)

## محتويات المشروع
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية (المساعد، الأنظمة، الأسئلة، بلّغ) |
| `css/style.css` | التصميم، ومهيأ للشاشة الطولية التي تعمل باللمس |
| `js/app.js` | عرض شخصيتك، المايك، الصوت، والمحادثة. **الإعدادات في أعلى الملف** |
| `js/law-data.js` | نص نظام هيئة الرقابة ومكافحة الفساد كاملاً، مقسماً إلى مواد |
| `js/quiz-data.js` | 12 سؤالاً من النظام (تقدر تعدلها أو تضيف عليها) |
| `server.js` | الخادم الذي يربط الموقع بـ ChatGPT (OpenAI)، ويبقى المفتاح فيه مخفياً |
| `data/nazaha-law.txt` | نص النظام الذي يعتمد عليه الذكاء الاصطناعي في إجاباته |
| `assets/` | شعار جامعة حائل وشعار نزاهة |

## كيف يشتغل المساعد الصوتي
1. الزائر يضغط على المايك ويتكلم، والتسجيل يتوقف تلقائياً إذا سكت.
2. الصوت يتحول إلى نص عبر OpenAI.
3. ChatGPT يجاوب بلهجة سعودية، معتمداً على نص النظام.
4. الجواب يتحول إلى صوت عبر OpenAI TTS، وفم الشخصية يتحرك مع الصوت.

> إذا ما فيه اتصال بالذكاء الاصطناعي، الموقع يظل شغالاً بإجابات محلية جاهزة لأشهر الأسئلة.

## خطوات التشغيل
### 1) مفتاح OpenAI
- اشتراك ChatGPT Plus **ما ينفع هنا**. تحتاج مفتاح API من: platform.openai.com وتضيف فيه رصيداً.
- انسخ ملف `.env.example` باسم `.env` وحط المفتاح فيه:
```
OPENAI_API_KEY=sk-...
```

### 2) التشغيل على جهازك للتجربة
تحتاج Node.js إصدار 18 أو أحدث، والمشروع ما يحتاج `npm install`:
```
node server.js
```
بعدها افتح: http://localhost:3000

### 3) الاستضافة
يحتاج الموقع استضافة **تشغّل Node.js**، لأن الاستضافة العادية للملفات فقط (HTML) ما تكفي.
- **Render.com** أو **Railway.app**: ارفع المجلد على GitHub واربطه، وأمر التشغيل `node server.js`، وأضف `OPENAI_API_KEY` في Environment Variables.
- **سيرفر VPS**: شغّله بـ `pm2 start server.js`، وحط قدامه Nginx مع شهادة SSL.

⚠️ **المايك ما يشتغل إلا على HTTPS** (أو localhost). كل الاستضافات المذكورة فوق تعطيك HTTPS تلقائياً.

### 4) تشغيله على الشاشة التفاعلية
افتح Chrome بوضع الكشك (ملء الشاشة بدون أشرطة):
```
chrome --kiosk --autoplay-policy=no-user-gesture-required https://رابط-موقعك
```
- أول مرة اسمح للمتصفح باستخدام المايك.
- الموقع يرجع للشاشة الرئيسية ويمسح المحادثة إذا ما لمسه أحد لمدة دقيقتين. تقدر تغير المدة من `idleResetSeconds` في `js/app.js`.

## الإعدادات (اختياري)
في ملف `.env`:
- `TTS_VOICE`: صوت الشخصية. الافتراضي `onyx` وهو صوت رجالي عميق، وتقدر تجرب `ash` أو `echo`.
- `OPENAI_MODEL`: نموذج المحادثة، والافتراضي `gpt-4o-mini` (سريع واقتصادي).
- إذا غيّرت OpenAI أسماء النماذج، عدّلها هنا بدون ما تلمس الكود.

لتعديل أسلوب الشخصية أو تعليماتها: عدّل `SYSTEM_PROMPT` في `server.js`.

## إضافة شخصيتك
الموقع جاهز يستقبل الشخصية اللي تصممها. حط ملفاتك في مجلد `assets/` بهذه الأسماء:

| الملف | الاستخدام |
|---|---|
| `avatar-idle.mp4` | فيديو الشخصية وهي ساكتة، يتكرر بشكل سلس (5 إلى 10 ثوانٍ) |
| `avatar-talk.mp4` | فيديو الشخصية وهي تتكلم، ويظهر تلقائياً وقت ما يرد نزيه |
| `avatar.jpg` | **أو** صورة ثابتة بدل الفيديو، وتتحرك حركة خفيفة أثناء الكلام |

- يكفي ملف واحد. وإذا حطيت الفيديو والصورة مع بعض، الفيديو هو اللي يظهر.
- إذا ما فيه أي ملف، يظهر إطار مكتوب فيه «مكان الشخصية».
- إذا كانت أسماء ملفاتك أو امتداداتها مختلفة، غيّرها من أعلى ملف `js/app.js`.
- يفضّل أبعاد طولية قريبة من 400×470 وبخلفية شفافة أو فاتحة.

## ملاحظات مهمة
- قبل العرض النهائي **راجع الأنظمة والأسئلة**. نص نظام الهيئة منقول حرفياً من الملف المعتمد، أما الأنظمة الأخرى فمكتوبة كملخصات ومعها رابط هيئة الخبراء.
- استخدام شعار نزاهة يحتاج تنسيقاً أو موافقة من الهيئة حسب أنظمة الجامعة.
- تكلفة الاستخدام: بالنماذج الافتراضية تكون تكلفة الفعالية الكاملة بسيطة غالباً (قروش لكل سؤال)، ويفضّل تحط حداً للصرف في حساب OpenAI.
